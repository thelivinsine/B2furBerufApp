Section 1

Dark mode: colour and contrast

Two separate problems, one section. Contrast: today a card lifts only 1.34 to 1 off the ground, and the answer rows inside the question tile carry exactly the same colour as the tile itself, so they vanish and only the thin border is left. Colour: the greys are not grey. Today's dark ground is a blue at 44 % saturation, and two soft blue glows sit on top of it, which is where the "too much blue" comes from.

You said K2 is about the contrast you expect, so all four options below carry exactly that contrast relationship: card 1.4 to 1 off the ground, a clearly visible card edge at 3.1, and one layer rule (ground → card → row inside the card). They differ only in how much hue is left in the greys. N1, N2 and N3 also switch the two blue page glows off.

The reference apps do the same thing: VS Code and ChatGPT use plain neutral greys, Claude uses a slightly warm grey, GitHub keeps a whisper of cool in it. All four spend colour on one accent and nothing else, which is what makes the blue register when it does appear. These are brand tokens, so a pick applies app-wide, which is why each column also shows a Bibliothek card.

Section 2

Corner rounding, two steps down

The app derives every radius from a single number, so one change moves every card, row and number at once. Today a card sits at 18 px. New is one notch down (14 px), Tighter is the next one (10 px), which is roughly where VS Code and GitHub sit. It stays a soft corner (the brand rule is "squircle, never circle"), it just reads more precise the tighter it gets. Section 4

Three layouts for the exam screen

Shared by all three: a bigger question type size (16 instead of 14 px), more inner padding, the number row at the bottom, air around the buttons, draggable tiles, and a reset to the default sizes on every question change. What differs is where the leftover room goes when a text is short, so switch to Text: Short above and compare the three. Try the dragging too, then hit "Weiter": the tiles snap back.

What does not change: the exam screen stays exactly one screen tall, with no page scrolling and internal scrolling in the text tile, and the question tile stays fully visible at all times. The desktop frames simulate a 1200 px wide window, the phone frames a 360 px device, which is the tightest case the exam has to survive.
