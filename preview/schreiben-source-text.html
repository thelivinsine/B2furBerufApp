Schreiben: the text a learner reacts to

Audit P4. 71 tasks (54 Stellungnahmen, 17 Forumsbeiträge) ask the learner to react to a position that the instruction only describes. Reacting to a described position is vaguer and easier than reacting to a stated one: there is no wording to pick up, no claim to quote back, nothing concrete to refute. It is also where the bank diverges most from the exam shape it is modelled on, where the writing task is a reaction to a supplied text.

The schema already has the field (source), set on 0 of 717 tasks and read by nothing. Below are three ways the supplied text can sit on the Aufgabe card. Everything else on the card is unchanged: same eyebrow, same shuffle and expand buttons, same Leitpunkte, same editor underneath. Pick A, B or C.

The example used in all three

Task wt_bildung_l10, a C1 Forumsbeitrag. Today the learner sees only the instruction: "In einem Forum wird gefragt, ob Sprachkurse neben der Arbeit realistisch sind." With a source, they see the actual post, with a claim in it worth disagreeing with.

Text zur Aufgabe

Aus dem Rundschreiben der Hausleitung: Ab Oktober stellen wir die Stationsküche auf Mehrweggeschirr um. Wir rechnen mit höheren Anschaffungskosten, aber mit deutlich weniger Abfall. Rückmeldungen aus den Teams nehmen wir bis Ende des Monats entgegen.

What each option costs

Option What the learner meets first Cost
A Text first The forum post or the mail, then what to do with it. This is the order a real exam paper uses, and the order the situation has: something arrives, then you answer it. The card opens with content that is not an instruction, so the eyebrow no longer sits directly above the task sentence.
B Task first The instruction, then the text it refers to, then the Leitpunkte. Reads slightly backwards ("write a reply" before there is anything to reply to), but keeps the card's current opening line exactly where it is today.
C Folded The instruction, a one-line "Text zur Aufgabe lesen", then the Leitpunkte. Shortest resting card, but the text becomes optional in practice, and an exam text is not optional. Adds a control to a card that today has exactly two.

The same tile in the Modelltest

Whichever option you pick, the exam's Schreiben part renders the identical tile above its brief, so a task looks the same whether it is practised or sat under a clock. Nothing else about the exam stage changes.

What ships with it

71 short German texts, one per Stellungnahme and Forumsbeitrag, each stating a position in three or four sentences that the Leitpunkte can actually argue against. The text also goes to the AI evaluator, so "Aufgabenerfüllung" can finally check whether the learner responded to what was said, instead of to a paraphrase. No ids change; no other task is touched.
