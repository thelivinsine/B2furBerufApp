AI usage, made visible

You asked for something like Claude Code's usage readout: the app should say, wherever a feature uses AI, that it is using AI and how much of today's free allowance is left. This page is the second half of that job. Pick one chip design and one AI mark.

What is already done, and what this page decides

Done  Part A: no AI feature is silent any more. The sentence transformation in Fokus (the "Nochmal" / grammar-dial feature) had its own daily cap of 30 and no readout at all, so learners could hit that wall with no warning. It is now counted and shown like every other AI feature, on its own budget, because a transformation has never cost a correction.

This page  Part B: one reserved KI chip. Today the count is a plain grey line of text that only appears in four places, and it is never seen before the AI runs. Part B gives the app one mark that always means "this uses AI", carrying its own count, placed on every control that spends a unit.

One thing deliberately not copied from Claude Code: money and token numbers. Claude Code shows those because the user pays the bill. Your learners do not, so a euro figure would only be alarming. The learner-facing number stays "how many free AI helps do I have left today".

The four options

Each option is drawn in the same three places, with the real colours and the real button sizes. Use the switches above to see it in dark mode, and to see what it looks like when the day's allowance is nearly gone or used up.

Option A

Quiet line, one mark added

Keeps today's grey sentence and only puts the KI mark in front of it, then repeats it on the controls that are missing it. Quietest and cheapest. Weakness: grey body text is easy to miss, which is the complaint that started this.

Option B

Accent chip beside the button

A small Himmelblau chip, the same fill as the filter rails, holding the mark and the count: KI 7/10. Reads at a glance, sits next to the button that spends it, and turns grey when the day is used up. Weakness: one more object beside every AI button.

Option C

The count rides on the button

Nothing floats beside the button, because the count is inside it: the button says what it costs. Tightest layout of the four and impossible to miss. Weakness: the button grows wider, which is tight on a 360px phone, and at zero the button still has to read as pressable (it stays pressable: cached answers are free).

Option D

Chip with a dot meter

Option B plus a row of dots that empties through the day, so the learner sees how much is left without reading a number. Weakness: it only works for small allowances. Ten dots for Fokus is already a lot, thirty for the transformations is impossible, so those fall back to the number alone and the chip is then not quite the same object everywhere.

The mark itself

Whichever chip you pick, it needs one symbol that means AI and nothing else. The sparkle icon cannot be it: the app already uses sparkles for the quiz, for empty states and in onboarding, so it would mean two things at once. Three candidates, shown at real size.

Mark 1 · KI monogram, accent
KITwo letters, no icon. Says it in words, in German, and never collides with an existing icon.
Mark 2 · KI monogram, brand blue
KIThe same, in the brand action colour. Louder, and it competes with the buttons beside it.
Mark 3 · Spark glyph
✦Icon only. Needs the sparkle removed from the quiz and onboarding first, so it costs an extra pass.
