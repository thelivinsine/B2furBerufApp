Mobile: fading the list behind the Üben button

On desktop the Bibliothek list scrolls inside its own column, so it fades softly into the page ground at the bottom edge (the mask-fade-bottom effect in your screenshot). On a phone the page itself scrolls, so there is no such edge: word cards run all the way down and pass directly behind the floating "Üben" button and the "Etwas verbessern? Feedback geben" line under it, which is why that line is hard to read.

Each option below adds the same kind of soft dissolve on mobile: a veil in the page-ground colour, pinned above the bottom nav, sitting under the button and over the cards. It never blocks taps, and it holds no border, so there is no bar strapped across the screen.

The phones scroll. Scroll a list up to see the cards pass into the fade.

What each option costs

OptionWhat you seeTrade-off
Today Cards run at full strength right up to the nav; the grey feedback line prints over a white card. The line is illegible whenever a card happens to sit under it.
A · Short fade The last ~112 px dissolve. The button sits on clean ground, the line is clear. Cards still read strongly right up to the button, so it is the least "premium" of the three but also the least likely to hide content you wanted to see.
B · Long fade The dissolve starts ~176 px up, so a card melts away gradually. Closest in feel to the desktop edge in your screenshot. A word card sitting in the fade zone is dimmed while still on screen, so the visible list is effectively a little shorter.
C · Fade + soft blur Same dissolve as A/B plus a blur that ramps in toward the bottom, like frosted glass. Richest look, but it is the closest to a "blurred band", which you rejected for the browse toolbar. Also the heaviest to render on older phones.

Notes

The veil is painted in --background, which matches the page ground almost exactly in light mode and is identical to it in dark mode, so it never shows as a coloured band. It is mobile only; desktop keeps the mask it already has. Whichever option you pick applies to all four Bibliothek tabs at once, since they share one cluster.
